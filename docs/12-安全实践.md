# 12 - 安全实践

> 对应源码：`src/main/features/security.ts` | 演示页：安全实践

## 一、原理

Electron 应用 = Chromium + Node.js，两者结合带来了强大的能力，也带来巨大攻击面。安全基线：

1. **contextIsolation: true**（默认）：渲染进程与 Node 隔离，preload 只暴露白名单 API（本工程 preload/index.ts 是范例）
2. **sandbox: true**（生产推荐）：渲染进程运行在沙箱中，进一步限制能力
3. **权限白名单**：页面请求摄像头/麦克风/剪贴板等权限，必须经主进程裁决
4. **导航拦截**：防止页面被引导跳转到外部网站（防钓鱼）
5. **禁用 webview**：webview 是高风险组件，默认应禁用
6. **CSP**：为渲染进程配置内容安全策略

## 二、关键代码

```ts
import { session } from 'electron'

// ① 权限白名单：只放行明确授权的权限
const allowed = new Set(['clipboard-read'])
session.defaultSession.setPermissionRequestHandler((wc, permission, callback) => {
  if (allowed.has(permission)) {
    callback(true)
  } else {
    callback(false)
    wc.send('security:permission-denied', permission) // 通知页面
  }
})

// ② 导航拦截：所有 webContents 创建时挂载
app.on('web-contents-created', (_e, contents) => {
  contents.on('will-navigate', (event, url) => {
    if (!isInternalUrl(url)) {
      event.preventDefault()
      shell.openExternal(url) // 转交系统浏览器
    }
  })
  // ③ 禁用 webview
  contents.on('will-attach-webview', (event) => event.preventDefault())
})
```

⚠️ **两套机制别混淆**（本工程演示页曾因此被误读）：
- **权限白名单**（`setPermissionRequestHandler`）：页面请求浏览器权限（摄像头/麦克风/地理位置/通知等）→ 白名单外**拒绝**，并推送 `security:permission-denied` 记录。演示页 ① 用 `navigator.geolocation` 触发（白名单外 → 被拒并记录）。
- **窗口/导航拦截**（`setWindowOpenHandler` / `will-navigate`）：`window.open` 或跳转外部站点 → **转交系统浏览器打开**（`shell.openExternal`），应用内不新开窗口。"打开浏览器"是预期设计，不是拦截失效。演示页 ② ③ 演示。

### 补充：两个权限处理器的区别

| 处理器 | 交互方式 | 适用 |
|--------|---------|------|
| `setPermissionRequestHandler` | 有回调（可通知页面"被拒绝"） | 用户可见的权限请求（security.ts ①） |
| `setPermissionCheckHandler` | 无 UI 静默返回 boolean | permissions.query 等无界面查询（security.ts ①.5，可开关演示） |

两者共用同一白名单，生产按需组合使用。

CSP（渲染进程 index.html 中）：

```html
<meta
  http-equiv="Content-Security-Policy"
  content="default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'"
/>
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/security.ts`
2. `index.ts` 中调用 `registerSecurity()`
3. 渲染进程监听权限拒绝事件：

```ts
window.api.security.onPermissionDenied((permission) => {
  // 提示用户权限被拒绝
})
```

## 四、安全清单（上线前自查）

- [ ] `contextIsolation: true`（永远开启）
- [ ] `sandbox: true`（生产环境）
- [ ] `nodeIntegration: false`（永远关闭）
- [ ] 外部链接一律 `shell.openExternal`
- [ ] 权限白名单按需最小化
- [ ] 渲染进程配置 CSP
- [ ] 不信任渲染进程传来的任意路径（文件操作需白名单）
