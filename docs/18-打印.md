# 18 - 打印 / 导出 PDF

> 对应源码：`src/main/features/print.ts` | 演示页：打印 PDF

## 一、原理

两种打印方式：

| 方式 | API | 场景 |
|------|-----|------|
| 导出 PDF | `webContents.printToPDF()` | 报表存档、网页转 PDF |
| 系统打印 | `webContents.print()` | 走打印机输出 |

两者参数类似：`printBackground`（含背景）、`pageSize`（纸张）、`margins` 等。

## 二、关键代码

```ts
// 生成 PDF（返回 Buffer）
const pdf = await win.webContents.printToPDF({
  printBackground: true,
  pageSize: 'A4'
})

// 保存对话框 → 写文件
const { filePath } = await dialog.showSaveDialog(win, {
  defaultPath: '页面.pdf',
  filters: [{ name: 'PDF', extensions: ['pdf'] }]
})
await fs.writeFile(filePath, pdf)
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/print.ts`
2. `index.ts` 中调用 `registerPrint(getMainWindow)`
3. 渲染进程：

```ts
const res = await window.api.print.toPdf({ defaultName: '我的报表.pdf' })
if (res.ok) console.log('已保存到', res.path)
```

## 四、生产最佳实践

- **报表模板**：创建隐藏窗口加载专用模板页面，对该窗口 `printToPDF`，主窗口不受影响
- **分页**：CSS `@page` 控制打印分页与边距
- **打印预览**：生产可用 `webContents.print()` 的静默模式直接送打印机

## 五、扩展：内置 PDF 查看器

导出后可用 **WebContentsView** 在窗口内查看 PDF（Chromium 内置查看器，支持缩放/翻页/打印）：

```ts
// 渲染进程（本工程打印页的"在窗口内查看 PDF"按钮）
const fileUrl = 'file:///' + pdfPath.replace(/\\/g, '/')
await window.api.protocol.openView(fileUrl, { topInset: 36 }) // 预留顶部返回条
await window.api.protocol.closeView()
```

无需额外配置（Electron 内置 PDF 查看器默认可用）。

⚠️ **教学要点一：WebContentsView 必须手动转移焦点**

`addChildView` 不会把键盘焦点交给 WebContentsView，且**新视图渲染进程未就绪时
`focus()` 是空操作**（`loadURL` 前调用无效），所以焦点往往仍在主页面 → 内嵌视图的
`before-input-event` 收不到 ESC（表现为"打开的 PDF 无法关闭"）。正确做法：

```ts
win.contentView.addChildView(view)
view.webContents.focus()                        // 立即尝试（渲染就绪后生效）
view.webContents.on('did-finish-load', () => view.webContents.focus()) // 加载后再移交
// 主页面也注册 ESC 兜底：无论焦点在哪个 webContents，ESC 都能关闭视图
win.webContents.on('before-input-event', (e, input) => {
  if (input.type === 'keyDown' && input.key === 'Escape') view.webContents.close()
})
// 关闭时把焦点还给主页面，否则主页面无法输入
win.webContents.focus()
```

⚠️ **教学要点二：原生叠加层 vs 页面控件**

WebContentsView 是**原生视图，叠在页面渲染之上**——页面里 `position: fixed` + 高
`z-index` 也盖不住它。要在视图之上放可见控件（如"返回本页"按钮），只能让视图**不覆盖
该区域**：`setBounds({ y: topInset, height: height - topInset })` 预留顶部条，
页面在顶部条渲染固定控件即可（本工程 `view:open` 支持 `topInset` 选项，打印页用 36px）。
