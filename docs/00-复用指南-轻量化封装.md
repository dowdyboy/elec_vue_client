# 00 - 复用指南（轻量化封装）

> 目标：让本项目的每个特性可被其他 Electron 项目以**简单、独立、安全、轻量**的方式复用，保持教学模板可复制性。

## 一、快速复制（3 步）

以 `clipboard` 为例：

```bash
# 方式 A：脚本一键复制（推荐）
node scripts/copy-feature.mjs clipboard ../my-app
# 方式 B：手动复制
# 1. 拷贝主进程文件
cp src/main/features/clipboard.ts ../my-app/src/main/features/
# 2. 在 ../my-app/src/main/index.ts 中注册
import { registerClipboard } from './features/clipboard'
# app.whenReady 内：registerClipboard()
# 3. 拷贝 preload 分组（搜索 clipboard 定位 api.clipboard）
```

脚本会同步提示：

- `preload` 中对应 `api.xxx` 分组需手动粘贴的关键词
- 额外依赖（如 `betterSqlite` 需 `better-sqlite3`）

## 二、轻量化设计要点

| 目标     | 做法                                                                             | 位置                                                                |
| -------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **简单** | 通道常量集中 `IPC.*` 可选导入；失败返回 `{ok:false}` 统一                        | `src/main/ipcChannels.ts` `src/shared/types.ts`                     |
| **易用** | 模板 `_template.ts` + 脚本 `copy-feature.mjs` + 本文档                           | `src/main/features/_template.ts`                                    |
| **独立** | 每个 `registerX(): Disposer` 自闭环，退出时统一 `before-quit` 释放               | `src/main/utils/disposable.ts` `src/main/index.ts:featureDisposers` |
| **安全** | 敏感通道校验 `isTrustedSender(event)`；分区窗口提示 `registerSecurityForSession` | `src/main/utils/validateSender.ts` `security.ts`                    |
| **轻量** | 不引入 Pinia/新依赖；`features/` 保持平铺；双 SQLite 保留                        | —                                                                   |

## 三、独立性：资源释放

已为易泄漏模块添加 `Disposer` 返回：

- `fileSystem` → `disposeFileSystemWatchers()` + `ipcMain.removeHandler`
- `socket` → `disposeSockets()`（TCP Server/Client + UDP Sockets）
- `httpServer` → `disposeHttpServer()` + `server.close()`
- `socketServer` → `disposeSocketServer()` + `io.close()`
- `quitGuard` → 移除 `before-quit` 监听与 handlers

`src/main/index.ts` 在 `app.whenReady` 收集到 `featureDisposers`，`app.on('before-quit')` 统一调用并 `setQuitting(true)`，避免端口占用与 `EADDRINUSE`。

新特性请遵循：

```ts
export function registerYourFeature(getMainWindow): Disposer {
  ipcMain.handle('your:chan', handler)
  return () => {
    ipcMain.removeHandler('your:chan')
    // clearInterval / server.close() 等
  }
}
```

## 四、安全性：最小可用校验

`src/main/utils/validateSender.ts`：

```ts
import { isTrustedSender, FORBIDDEN } from '../utils/validateSender'
ipcMain.handle('shell:openPath', async (e, p) => {
  if (!isTrustedSender(e)) return FORBIDDEN
  // ...
})
```

已内置校验的敏感通道：`shell:openPath/showInFolder/trash` `fileIcon:get` `inject:execute` `cert:setVerifyMode`。其他读写类通道建议按需添加。

分区窗口（`partition.ts`）默认不受 `security.ts` 保护，需：

```ts
import { registerSecurityForSession } from './features/security'
import { session } from 'electron'
registerSecurityForSession(session.fromPartition('persist:work'))
```

`preload` 的 `MessageChannel` 端口转移已将 `postMessage('*')` 收紧为 `location.origin`（`file://` 下回退 `*`）。

## 五、简单性：通道常量与共享类型

- `src/main/ipcChannels.ts`：`as const` 集中通道名，按需 `import { IPC } from '../ipcChannels'`，typo 编译期报错。
- `src/shared/types.ts`：收敛 `ShellOpenResult` `NotificationOptions` `ThemeSource` 等，避免主/preload 重复定义。

两者均为**可选**依赖，不引入也不影响运行，仅在追求可维护时使用。

## 六、他项目最小依赖

| 特性           | 额外依赖                                               | 备注               |
| -------------- | ------------------------------------------------------ | ------------------ |
| `betterSqlite` | `better-sqlite3` + `electron-builder install-app-deps` | 原生模块需 rebuild |
| `socketServer` | `socket.io`                                            |                    |
| `network`      | `axios`                                                | 可换 `net.request` |
| `autoUpdater`  | `electron-updater`                                     | 需配置 `publish`   |

其余 50+ 特性零额外依赖。

