# 21 - 进阶工程实践（配置与生产化）

> 本页内容为生产工程常用的配置/实践，不涉及新模块，按需查阅。

## 一、sandbox 与安全配置（生产必改）

本工程教学保持 `sandbox: false`（模板默认），生产发布前建议：

```ts
// src/main/index.ts
webPreferences: {
  preload: join(__dirname, '../preload/index.js'),
  sandbox: true,        // 生产：开启沙箱
  contextIsolation: true, // 永远开启（已开启）
  nodeIntegration: false  // 永远关闭（默认）
}
```

注意：`sandbox: true` 时 preload 中不能使用 Node API（如 `process.cwd()`），
需在 `contextBridge` 暴露前移除对 Node 模块的直接引用（本工程 preload 仅用 Electron 内置 API，可直接开启）。

## 二、远程调试（排查渲染进程问题）

```bash
# 启动时附加调试端口（Chrome DevTools 协议）
electron . --remote-debugging-port=9222
# 浏览器打开 http://localhost:9222 查看所有页面
```

生产环境排查利器：可结合 `--inspect` 调试主进程：

```bash
electron . --inspect=5858
```

## 三、崩溃上报（Sentry 接入）

```ts
import * as Sentry from '@sentry/electron/main'

Sentry.init({ dsn: 'https://xxx@sentry.io/xxx' })

// 结合 errorHandler.ts 的捕获点，把错误抛给 Sentry
process.on('uncaughtException', (error) => {
  Sentry.captureException(error)
})
```

## 四、contentTracing（性能分析）

```ts
import { contentTracing } from 'electron'

await contentTracing.startRecording({ include_categories: ['*'] })
// ... 运行需要分析的功能 ...
const trace = await contentTracing.stopRecording()
// 导出 trace 文件，用 chrome://tracing 或 Perfetto 分析
```

## 五、webview 标签（不推荐）

`<webview>` 标签功能与 WebContentsView 类似，但官方已不推荐：

- 安全性差（有大量历史漏洞 CVE）
- 渲染模型与现代浏览器不一致
- **推荐替代**：`WebContentsView`（见 docs/16）或 BrowserWindow + `win.loadURL`

## 六、数据持久化方案（electron-store）

小体量配置数据（窗口偏好、用户设置）用 electron-store（比手写 JSON 更完善）：

```bash
npm i electron-store
```

```ts
import Store from 'electron-store'

const store = new Store()
store.set('theme', 'dark')
const theme = store.get('theme')
```

本工程 windowState.ts 手写 JSON 是为了展示原理；生产可用 electron-store 替代。

## 七、日志方案（electron-log）

```bash
npm i electron-log
```

```ts
import log from 'electron-log/main'
log.initialize()
log.info('应用启动')
// 日志自动写入 userData/logs/main.log
```

## 八、图标与安装包定制

- 应用图标：`build/icon.png`（512x512）→ electron-builder 自动生成各平台尺寸
- NSIS 安装器：`electron-builder.yml` 的 `nsis` 段（artifactName、shortcutName 已配置）
- 自定义安装界面：NSIS 脚本 + `nsis.include`（进阶，按需查阅 electron-builder 文档）
