# 24 - 自定义协议内容（protocol.handle）

> 对应源码：`src/main/features/protocolContent.ts` | 演示页：会话管理 → ③

## 一、与"深链接"的区别（重要）

| | 深链接（docs/16） | 本模块（protocol.handle） |
|---|---|---|
| 注册方式 | `setAsDefaultProtocolClient` | `registerSchemesAsPrivileged` + `protocol.handle` |
| 触发方 | **系统**（点击外部链接唤起应用） | **应用内部**（fetch 请求 URL） |
| 作用 | 唤起应用并传参 | 返回自定义内容（虚拟文件/数据） |
| 类比 | 浏览器"打开外部协议" | 自定义 URL 协议的 Web 服务器 |

## 二、原理

`protocol.handle` 让主进程像 Web 服务器一样响应指定协议的请求：

```
渲染进程 fetch('elec-fs://demo/hello.txt')
        ↓
主进程 protocol.handle 回调 → 返回 Response 对象
```

典型用途：虚拟文件系统、离线资源包（图标/文档内置在 asar 外）、流式数据接口。

## 三、关键代码

```ts
// ① 必须在 app ready 之前声明协议特权
protocol.registerSchemesAsPrivileged([
  {
    scheme: 'elec-fs',
    privileges: {
      standard: true,     // 按标准 URL 语义解析（host/pathname 可用）
      secure: true,       // 视为安全来源
      supportFetchAPI: true, // 渲染进程可用 fetch()
      corsEnabled: true   // 允许跨源 fetch（页面源与 elec-fs:// 不同源时必须声明）
    }
  }
])

// ② app ready 之后注册处理器
protocol.handle('elec-fs', (request) => {
  const url = new URL(request.url)
  if (url.pathname === '/hello.txt') {
    return new Response('虚拟文件内容', {
      headers: { 'content-type': 'text/plain; charset=utf-8', 'access-control-allow-origin': '*' }
    })
  }
  return new Response('404', { status: 404, headers: { 'access-control-allow-origin': '*' } })
})
```

渲染进程读取（CSP 需放行 `connect-src`）：

```ts
const text = await (await fetch('elec-fs://demo/hello.txt')).text()
```

## 四、复制到新工程的步骤

1. 复制 `src/main/features/protocolContent.ts`
2. `index.ts` **顶层**（whenReady 前）调用 `registerProtocolSchemes()`；whenReady 内调用 `registerProtocolContent()`
3. index.html 的 CSP `connect-src` 增加协议名（如 `elec-fs:`）

## 五、常见问题

- **协议不生效**：`registerSchemesAsPrivileged` 必须在 app ready 前，且**不能重复调用**
- **fetch 被 CSP 拦截**：检查 `connect-src`（本工程已配 `'self' elec-fs:`）
- **fetch 报 Failed to fetch（跨源 CORS）**：页面源与自定义协议不同源时，特权必须加
  `corsEnabled: true`，且 handler 响应需带 `Access-Control-Allow-Origin` 头（本工程已修）。
  官方示例不报错是因为示例页面由协议自身加载（同源），不触发 CORS
- **host 语义**：`standard: true` 后 `elec-fs://demo/hello.txt` 的 host 是 `demo`，pathname 是 `/hello.txt`
