# TS-07 - 函数惯用法

> 对应演示页：TypeScript 惯用法 → 函数惯用法（路由 `/ts/function`）

## 一、惯用法是什么

函数是 TS 里用得最多的场景。默认参数、rest、重载、自定义类型守卫，能让 API
既好用又类型安全——尤其"类型守卫"是干净处理 `unknown` 的关键。

## 二、关键代码

```ts
// 默认参数 + rest
function greet(name: string, title = '同学'): string {
  return `你好，${title}${name}`
}
function sum(...nums: number[]): number {
  return nums.reduce((a, b) => a + b, 0)
}

// 函数重载：多组对外签名
function format(input: number): string
function format(input: Date): string
function format(input: number | Date): string {
  if (typeof input === 'number') return input.toFixed(2)
  return input.toLocaleDateString()
}

// 自定义类型守卫：返回 boolean 的同时收窄类型
function isStringArray(value: unknown): value is string[] {
  return Array.isArray(value) && value.every((v) => typeof v === 'string')
}
function process(input: unknown): string[] {
  if (isStringArray(input)) {
    return input   // 这里 input 已是 string[] ✅
  }
  return []
}
```

## 三、常见陷阱

- 重载顺序有讲究：更具体的签名放前面；实现签名不对外可见。
- 类型守卫函数必须返回 `value is T` 的精确形式，且内部逻辑要对（守卫是信任承诺）。

## 四、与 Electron 实例对照

本工程 `window.api.error.onNew((record) => ...)` 等回调收到的载荷是 `unknown`，
处理前先用守卫/转换函数收窄（见 `LifecyclePage.vue` 的 ErrorRecord 处理）。
把 typeof/in/instanceof 组合封装成守卫函数，是"IPC 未知载荷安全化"的标准做法。
