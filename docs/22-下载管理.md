# 22 - 下载管理

> 对应源码：`src/main/features/download.ts` | 演示页：下载管理

## 一、原理

下载功能的两层能力：

| 能力 | 事件/API | 说明 |
|------|---------|------|
| 触发下载 | `webContents.downloadURL(url)` | 走 Chromium 网络栈 |
| 管理下载 | `session` 的 `will-download` 事件 + `DownloadItem` | 保存路径、进度、暂停/恢复/取消 |

**will-download** 在每次下载开始时触发：可修改保存路径、拦截（`event.preventDefault()` 后自行处理）、记录日志。

## 二、关键代码

```ts
session.defaultSession.on('will-download', (_event, item) => {
  item.setSavePath(join(app.getPath('userData'), 'downloads', item.getFilename()))

  // 进度更新（progressing | interrupted）
  item.on('updated', (_e, state) => {
    const percent = item.getReceivedBytes() / item.getTotalBytes()
  })

  // 完成（completed | cancelled | interrupted）
  item.on('done', (_e, state) => { /* 通知渲染进程 */ })
})

// 触发下载
win.webContents.downloadURL('https://example.com/file.zip')
// 控制
item.pause() / item.resume() / item.cancel()
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/download.ts`
2. `index.ts` 中调用 `registerDownload(getMainWindow)`
3. 渲染进程：

```ts
await window.api.download.start('https://example.com/file.zip')
window.api.download.onProgress(({ percent, filename }) => { /* 更新进度条 */ })
window.api.download.onDone(({ state, savePath }) => { /* 完成/失败处理 */ })
await window.api.download.pause(url) // 暂停（按 URL 管理）
```

## 四、最佳实践

- **保存路径**：生产环境用 `item.setSaveDialogOptions()` 弹保存框，或自定义下载目录 + 文件名冲突处理
- **中断续传**：`interrupted` 后可调用 `item.resume()` 续传（需服务器支持 Range）
- **下载与 webRequest**：下载请求也走 Chromium 栈，可被拦截（见 docs/23）
