# TS-11 - 类与面向对象

> 对应演示页：TypeScript 惯用法 → 类与面向对象（路由 `/ts/oop`）

## 一、惯用法是什么

Electron 项目里类常用于领域模型、服务封装。掌握访问修饰符、抽象类、
`implements` 与参数属性简写，就够用 90% 的场景。

## 二、关键代码

```ts
// 访问修饰符 + 只读：封装的最小实践
class Account {
  public readonly id: string
  private balance = 0
  protected owner?: string

  constructor(id: string) {
    this.id = id
  }
  deposit(amount: number): void {
    this.balance += amount
  }
  getBalance(): number {
    return this.balance
  }
}

// 抽象类：定义骨架，子类必须实现抽象成员
abstract class Storage {
  abstract read(key: string): Promise<string | null>
  abstract write(key: string, value: string): Promise<void>

  // 模板方法：复用抽象成员
  async readOrDefault(key: string, fallback: string): Promise<string> {
    return (await this.read(key)) ?? fallback
  }
}

// interface：契约 + implements
interface Shape { area(): number }
class Square implements Shape {
  constructor(private side: number) {}
  area(): number {
    return this.side ** 2
  }
}

// 参数属性简写：构造参数直接声明为成员
class Point {
  constructor(
    public x: number,
    public y: number
  ) {}
}
```

## 三、常见陷阱

- 需要共享实现用抽象类（可含模板方法）；只要契约用 interface。
- 能用 `readonly`/`private` 的地方尽量用，防止无意修改。

## 四、与 Electron 实例对照

本工程多处"Feature 注册"模式（`src/main/features/` 每个 `registerXxx`
工厂函数）即"契约优先"思想——先定义能力（注册函数签名/接口），再分实现。
面向接口/抽象类设计，让调用方只依赖能力而非实现。
