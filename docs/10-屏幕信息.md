# 10 - 屏幕信息

> 对应源码：`src/main/features/screenInfo.ts` | 演示页：屏幕信息

## 一、原理

`screen` 模块（仅主进程可用）提供：

- 所有显示器的位置、分辨率、缩放比（`scaleFactor`）
- 鼠标光标位置
- 显示器热插拔事件（`display-added` / `display-removed` / `display-metrics-changed`）

**典型用途**：多屏应用把窗口定位到指定显示器；按缩放比适配高分屏（如 2x 屏用 2 倍尺寸图片）。

## 二、关键代码

```ts
import { screen } from 'electron'

screen.getAllDisplays() // 所有显示器
// [{ id, bounds, scaleFactor, ... }]

screen.getPrimaryDisplay() // 主显示器
screen.getCursorScreenPoint() // 鼠标位置 { x, y }

// 显示器变化事件
screen.on('display-added', () => win.webContents.send('screen:changed'))
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/screenInfo.ts`
2. `index.ts` 中调用 `registerScreenInfo(getMainWindow)`
3. 渲染进程：

```ts
const info = await window.api.screen.getInfo()
// info.displays / info.cursor / info.primary

// 实时监听显示器变化
window.api.screen.onDisplaysChanged((info) => refresh())
```

## 四、实战：把窗口移到指定显示器

```ts
const display = screen.getAllDisplays()[1] // 第二块屏幕
win.setBounds({
  x: display.bounds.x + 100,
  y: display.bounds.y + 100,
  width: 800,
  height: 600
})
```
