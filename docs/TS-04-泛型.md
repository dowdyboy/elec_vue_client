# TS-04 - 泛型

> 对应演示页：TypeScript 惯用法 → 泛型（路由 `/ts/generics`）

## 一、惯用法是什么

泛型（Generics）让一段代码能处理多种类型，同时保留精确的类型关系——
"类型层面的参数"。数组、Promise、Map 都是泛型；IPC 封装、事件回调、工具函数
是最常见的应用场景。

## 二、关键代码

```ts
// 泛型函数：T 由实参推断
function first<T>(arr: T[]): T | undefined {
  return arr[0]
}
const a = first([1, 2, 3])        // a: number | undefined
const b = first(['x', 'y'])       // b: string | undefined

// 多个类型参数
function pair<A, B>(x: A, y: B): [A, B] {
  return [x, y]
}

// 约束：T 必须具备某能力
interface HasLength { length: number }
function longest<T extends HasLength>(a: T, b: T): T {
  return a.length >= b.length ? a : b
}
longest('abc', 'de')      // ✅
// longest(1, 2)          // ❌ number 没有 length

// 泛型接口 / 函数类型 / 类
interface Box<T> { value: T }
type Mapper<T, U> = (item: T) => U
class Stack<T> {
  private items: T[] = []
  push(item: T): void { this.items.push(item) }
  pop(): T | undefined { return this.items.pop() }
}
```

## 三、常见陷阱

- 优先依赖推断；只有推断不理想时才显式写 `<T>`。
- 约束用 `extends` 限定能力，避免"泛型变成了 any"。

## 四、与 Electron 实例对照

本工程 `src/preload/index.ts` 的 `window.api` 各方法本质是 `ipcRenderer.invoke`
的泛型封装：每个方法把 IPC 返回类型精确带给调用处。通用封装可写成
`async function invoke<T>(channel: string, ...args: unknown[]): Promise<T>`，
调用处 `await invoke<User>('user:get', id)` 即获得类型补全。
