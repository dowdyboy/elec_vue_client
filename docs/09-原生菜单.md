# 09 - 原生菜单

> 对应源码：`src/main/features/menu.ts` | 演示页：原生菜单

## 一、原理

Electron 的两类菜单都是原生控件（非 HTML）：

| 类型 | 位置 | 用途 |
|------|------|------|
| 应用菜单 | 窗口顶部（macOS 在系统顶部） | 全局命令：文件/编辑/窗口 |
| 上下文菜单 | 鼠标右键位置弹出 | 右键操作 |

`role` 是 Electron 内置行为（copy/cut/paste/quit/reload…），无需自己实现，自动适配系统快捷键。

## 二、关键代码

```ts
import { Menu } from 'electron'

// 应用菜单
Menu.setApplicationMenu(
  Menu.buildFromTemplate([
    { label: '文件', submenu: [{ label: '保存', accelerator: 'Ctrl+S' }] },
    { label: '编辑', submenu: [{ role: 'copy' }, { role: 'paste' }] }
  ])
)

// 上下文菜单（在指定窗口弹出）
const menu = Menu.buildFromTemplate([
  { label: '复制', role: 'copy' },
  { type: 'separator' },
  {
    label: '自定义项',
    click: () => win.webContents.send('menu:item-clicked')
  }
])
menu.popup({ window: win })
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/menu.ts`
2. `index.ts` 中调用 `registerMenu(getMainWindow)`
3. 渲染进程右键区域：

```ts
// 在右键事件中触发（坐标由 Electron 自动取鼠标位置）
window.api.menu.showContext()
```

## 四、最佳实践

- **外部链接**：菜单项打开网页必须用 `shell.openExternal`（不要 `win.loadURL` 替换掉应用页面）
- **macOS 第一个菜单**：必须命名为 `app.name`（显示在系统菜单栏）
- **菜单栏隐藏**：Windows/Linux 可用 `autoHideMenuBar: true`（按 Alt 显示）
