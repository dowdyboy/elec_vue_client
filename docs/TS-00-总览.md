# TS-00 - TypeScript 惯用法总览

> 对应演示页：侧边栏「TypeScript 惯用法」板块（路由 `/ts`）

## 一、板块定位

Electron 部分（docs/00~34）教"Electron 能力怎么用"；本板块教"**TypeScript 怎么写得专业**"。
两者互补：Electron 的每个演示页本身就在用 TS，本板块把 TS 常用类型能力与惯用法
系统地过一遍，并给出**本工程真实出处**，让你既会写类型、又知道生产代码里它长什么样。

## 二、学习路径

```
① 地基   类型标注与推断 → interface/type → 泛型
② 进阶   联合与收窄 → 工具类型 → 映射/条件类型
③ 实战   函数惯用法 → 异步惯用法 → 模块组织 → 类
④ 落地   与 Electron 结合（IPC 类型安全）
```

对应文档：TS-01 → TS-12。
