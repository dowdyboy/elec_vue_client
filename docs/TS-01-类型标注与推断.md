# TS-01 - 类型标注与推断

> 对应演示页：TypeScript 惯用法 → 类型标注与推断（路由 `/ts/intro`）

## 一、惯用法是什么

TypeScript 的价值在于**类型系统 + 自动推断**。类型标注让你显式声明意图；
推断让你"能不写就不写"。任何 TS 项目的第一步都是掌握基础类型与
`any / unknown / never` 三兄弟的取舍。

## 二、关键代码

```ts
// 基础类型与字面量类型
let name: string = 'Electron'
const count: number = 42
const list: number[] = [1, 2, 3]
const pair: [string, number] = ['version', 1]   // 元组

// 字面量类型：值本身作为类型（配合联合 = 轻量枚举）
type Direction = 'up' | 'down' | 'left' | 'right'
let dir: Direction = 'up'

// 推断：能不写就不写
let msg = 'hello'           // 推断为 string
function add(a: number, b: number) {
  return a + b              // 返回类型自动推断为 number
}

// any / unknown / never
let anything: any = 1       // 放弃检查（慎用）
let data: unknown = JSON.parse('{"a":1}')   // 安全，但需收窄后才能用
function fail(msg: string): never {         // 永不返回
  throw new Error(msg)
}

// const 断言：值固化为字面量类型
const CONFIG = { appName: 'elec-vue', version: 1 } as const
```

## 三、常见陷阱

- `any` 会"传染"：一个 any 变量传给函数后，函数参数的类型检查失效，错误一路溜走。
- `unknown` 不能直接访问属性/方法，必须先收窄（typeof / in / 类型守卫）。
- `const` 声明收窄为字面量类型、`let` 声明为宽类型——别混淆。
