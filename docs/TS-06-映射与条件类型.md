# TS-06 - 映射与条件类型

> 对应演示页：TypeScript 惯用法 → 映射与条件类型（路由 `/ts/mapped-conditional`）

## 一、惯用法是什么

这是 TS"类型编程"的核心：
- **映射类型**按规则批量生成属性（Mapped Types）；
- **条件类型**做类型级 if-else（`T extends U ? X : Y`）；
- **infer** 在条件里提取类型；
- **satisfies / as const** 让常量驱动类型。

理解它们，就能读懂绝大多数"类型体操"。

## 二、关键代码

```ts
// 映射类型：批量生成 + 重命名
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K]
}
interface User { name: string; age: number }
type UserGetters = Getters<User>   // { getName: () => string; getAge: () => number }

// 条件类型 + infer
type ElementType<T> = T extends (infer E)[] ? E : never
type C = ElementType<number[]>     // number
type IsString<T> = T extends string ? true : false
type A = IsString<'x'>             // true

// 分布式条件类型（联合逐个分发）
type Filter<T> = T extends string ? T : never
type E = Filter<string | number>   // string

// satisfies：校验但不丢失字面量精度
const palette = {
  red: [255, 0, 0],
  green: '#00ff00'
} satisfies Record<string, unknown>

// as const + typeof：常量驱动类型
const ROUTES = ['home', 'settings'] as const
type Route = (typeof ROUTES)[number]   // 'home' | 'settings'
```

## 三、常见陷阱

- 条件类型在**裸泛型参数**上会分发；不想分发用 `[T] extends [U]` 包一层。
- `satisfies` 保留精确推断；`as const` 固化字面量——两者用途不同，别混。

## 四、与 Electron 实例对照

本工程路由表（`src/renderer/src/router/index.ts`）就是"常量数组 + 派生类型"：
`menuOptions()` 从 `routes` 生成菜单，配合 `as const` 可派生路由路径联合类型。
`'常量数组 → 联合类型'`（`(typeof ROUTES)[number]`）是路由表、事件名集合的标准推导。
