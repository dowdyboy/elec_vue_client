# 00 - 项目总览与架构

## 一、三个进程

| 进程 | 职责 | 能力 |
|------|------|------|
| **主进程** (main) | 窗口、系统 API、文件、网络 | 完整 Node.js + Electron API |
| **预加载** (preload) | 安全桥：暴露白名单 API | 受限的 Node.js |
| **渲染进程** (renderer) | UI 展示与交互 | 浏览器能力（无 Node） |

通信方式：渲染进程 → `window.api.xxx`（preload 暴露）→ IPC → 主进程。

## 二、源码结构

```
src/
├── main/
│   ├── index.ts          # 入口：窗口创建 + 特性注册表（每行一个特性）
│   ├── types.ts          # MainWindowGetter 共享类型
│   └── features/         # ★ 模板核心：14 个独立特性模块
│       ├── windowManager.ts / ipcBridge.ts / tray.ts / ...
├── preload/
│   ├── index.ts          # contextBridge 暴露 window.electron + window.api
│   └── index.d.ts        # window.api 的类型声明
└── renderer/src/
    ├── App.vue           # 根组件：Naive UI 主题 + 侧边栏导航 + 内容区
    ├── router/index.ts   # vue-router（hash 模式）
    ├── stores/theme.ts   # 主题状态（与 nativeTheme 联动）
    ├── components/       # FeatureLayout（三段式布局）/ CodeBlock（源码展示）
    └── pages/            # 首页 + 14 个特性演示页 + 子窗口演示页
docs/                     # 本目录：14 篇教学文档
```

## 三、特性注册表模式（模板核心思想）

`src/main/index.ts` 中每个特性一行：

```ts
registerWindowManager(getMainWindow) // 窗口管理
registerIpcBridge()                  // IPC 通信
registerTray(getMainWindow)          // 系统托盘
// ... 其余特性
```

**增删特性 = 增删一行注册调用**。每个 `features/xxx.ts` 文件头部注释都写了"复制到新工程的步骤"。

## 四、UI 层说明

- 使用 **Naive UI**（`n-*` 组件），中文 locale，明暗主题与系统联动
- 每个演示页用统一的 `FeatureLayout` 三段式：原理说明 → 在线演示 → 关键源码
- 关键源码通过 vite `?raw` 导入，改主进程代码后页面自动同步

## 五、启动方式

```bash
npm install
npm run dev        # 开发（支持 HMR）
npm run build:win  # 打包 Windows 安装包
```

## 六、如何把特性复制到别的工程

以"系统托盘"为例：

1. 复制 `src/main/features/tray.ts` 到新工程
2. 在 `index.ts`（whenReady 内）调用 `registerTray(getMainWindow)`，传入窗口获取函数
3. 若需要渲染进程交互，复制 `src/preload/index.ts` 中对应的 `tray` 分组（如有）
4. 按需复制 `resources/icon.png` 托盘图标

> ⚠️ 注意：若新工程不使用 Naive UI，**UI 演示页**无法直接复制，
> 只需复制主进程 + preload 部分（这两部分与 UI 无关，可原样使用）。
