# 14 - 网络通信

> 对应源码：`src/main/features/network.ts` | 演示页：网络通信

## 一、原理

桌面应用网络请求的两种主流方案：

| 方案 | 位置 | 优点 |
|------|------|------|
| HTTP（axios） | **主进程** | 绕过浏览器 CORS、统一鉴权/错误处理/重试 |
| WebSocket（socket.io-client） | **渲染进程** | 浏览器原生能力，双向实时推送 |

**为什么 HTTP 放主进程？**
- 渲染进程的 `fetch` 受 CORS 限制，而主进程的 Node.js HTTP 客户端没有
- 便于集中管理 token、日志、超时重试

**为什么 WebSocket 放渲染进程？**
- 浏览器原生支持 WebSocket，无需主进程中转
- 实时数据流直接驱动 UI，链路更短

## 二、关键代码

```ts
// ── 主进程：HTTP 封装 ──
import axios from 'axios'

ipcMain.handle('network:httpGet', async (_e, url) => {
  try {
    const response = await axios.get(url, {
      timeout: 10000,
      validateStatus: () => true // 让 4xx/5xx 也返回数据
    })
    return { ok: true, status: response.status, data: response.data }
  } catch (error) {
    return { ok: false, error: error.message }
  }
})

// ── 渲染进程：WebSocket（socket.io-client）──
import { io } from 'socket.io-client'

const socket = io('https://your-server.com')
socket.on('connect', () => socket.emit('message', 'hello'))
socket.on('message', (data) => console.log('收到:', data))
```

## 三、复制到新工程的步骤

**HTTP**：
1. 复制 `src/main/features/network.ts`
2. `index.ts` 中调用 `registerNetwork()`
3. 渲染进程：`const res = await window.api.network.httpGet(url)`

**WebSocket**：直接复制渲染进程的 `io()` 用法（需 `npm i socket.io-client`，本工程已安装）。

## 四、最佳实践

- **超时必设**：`timeout: 10000`，避免请求挂死
- **统一错误结构**：返回 `{ ok, data | error }`（与文件系统模块一致），页面统一处理
- **鉴权**：token 在主进程统一注入 header，渲染进程无感知
- **socket 清理**：页面卸载时 `socket.disconnect()`，避免连接泄漏
