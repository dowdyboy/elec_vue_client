# TS-05 - 工具类型

> 对应演示页：TypeScript 惯用法 → 工具类型（路由 `/ts/utility`）

## 一、惯用法是什么

TypeScript 内置一批"类型变换"工具（Partial/Omit/Record 等）。它们不是运行时函数，
而是编译期的类型操作，能从已有类型快速派生新类型，大幅减少重复定义。

## 二、关键代码

```ts
interface User {
  id: string
  name: string
  email?: string
  age?: number
}

type PartialUser = Partial<User>          // 全部可选
type RequiredUser = Required<User>        // 全部必填
type ReadonlyUser = Readonly<User>        // 全部只读
type Picked = Pick<User, 'id' | 'name'>   // 只留 id/name
type Omitted = Omit<User, 'email'>        // 去掉 email
type State = Record<'idle' | 'loading' | 'done', boolean>   // 键→值映射

// 提取工具
function createUser(name: string, age: number): User { /* ... */ }
type CreateArgs = Parameters<typeof createUser>   // [name: string, age: number]
type CreatedUser = ReturnType<typeof createUser>  // User
type NonNull = NonNullable<string | null | undefined>  // string

// 实战：从"实体"派生"输入/更新载荷"（单一真相源）
interface Task { id: string; title: string; done: boolean; createdAt: number }
type TaskInput = Omit<Task, 'id' | 'createdAt'>
type TaskPatch = Partial<Pick<Task, 'title' | 'done'>>
```

## 三、常见陷阱

- `Partial` 只把已有属性变可选，**不会新增属性**。'部分可选的表单态'建议显式定义。
- `ReturnType<typeof fn>` 依赖 `typeof` 取函数类型，别在值上直接写 ReturnType。

## 四、与 Electron 实例对照

本工程 IPC 载荷与回调经常用工具类型派生：
- 事件载荷的结构化字段（如 `download.ts` 的 toRecord）本质是"对象类型精简"；
- `src/preload/index.d.ts` 里 `Api` 类型声明集中，配合工具类型可派生多个"视图类型"。
后端 DTO、表单校验、IPC 载荷建模的通用套路即"实体 + Omit/Pick/Partial"。
