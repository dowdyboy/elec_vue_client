# 03 - 系统托盘

> 对应源码：`src/main/features/tray.ts` | 演示页：系统托盘

## 一、原理

托盘（Tray）让应用常驻系统任务栏/菜单栏：即使关闭窗口，应用仍在后台运行。这是聊天软件、音乐播放器等"后台常驻"应用的核心能力。

托盘通常搭配**菜单**：右键托盘图标弹出操作项（显示窗口、退出等）。

## 二、关键代码

```ts
import { Tray, Menu, nativeImage } from 'electron'

// 1. 创建图标（icon 建议 16x16 或更大的 png，系统会自动缩放）
const icon = nativeImage.createFromPath(join(__dirname, 'icon.png'))
const tray = new Tray(icon)
tray.setToolTip('应用名称')

// 2. 左键点击：显示窗口
tray.on('click', () => {
  win.show()
  win.focus()
})

// 3. 右键菜单
tray.setContextMenu(
  Menu.buildFromTemplate([
    { label: '显示主窗口', click: () => win.show() },
    { label: '退出应用', click: () => app.quit() }
  ])
)
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/tray.ts` 到新工程（把 `icon.png` 换成自己的图标）
2. `index.ts` 中调用 `registerTray(getMainWindow)`（需先定义 `getMainWindow`）
3. 实现"关闭窗口隐藏到托盘"（本工程 index.ts 已实现，标准模式）：

```ts
let isQuitting = false

// 创建窗口时：拦截关闭事件 → 隐藏窗口
mainWindow.on('close', (event) => {
  if (!isQuitting) {
    event.preventDefault() // 阻止真正关闭
    mainWindow.hide()      // 隐藏到托盘
  }
})

// 托盘菜单"退出应用"调用 app.quit() 后，before-quit 置位退出标志
app.on('before-quit', () => {
  isQuitting = true
})
```

## 四、常见问题

- **图标不显示**：Windows 托盘图标按 16x16 缩放，图标为纯黑/纯白会看不见；用彩色图标
- **退出后进程残留**：托盘应用退出时一定要 `app.quit()`，否则进程常驻
- **macOS 注意**：macOS 的托盘在菜单栏（屏幕顶部），图标会自动转换为模板图标
