# TS-08 - 枚举与常量断言

> 对应演示页：TypeScript 惯用法 → 枚举与常量断言（路由 `/ts/enum-literal`）

## 一、惯用法是什么

描述"固定选项集"有两种主流方式：`enum`（运行时对象，可反向映射）与
`as const + 联合`（纯类型，更精确）。以及模板字面量类型——在字符串类型上做模式匹配。

## 二、关键代码

```ts
// enum：运行时真实对象（数字枚举可反向映射）
enum Color { Red, Green, Blue }
console.log(Color.Red)      // 0
console.log(Color[0])       // "Red"（反向映射）

enum Status {
  Idle = 'idle',
  Loading = 'loading',
  Error = 'error'
}

// as const + 联合：更"现代"的替代（无运行时对象，类型更精确）
const Statuses = { Idle: 'idle', Loading: 'loading', Error: 'error' } as const
type StatusT = (typeof Statuses)[keyof typeof Statuses]  // 'idle' | 'loading' | 'error'

// 模板字面量类型：字符串类型层面做模板
type Unit = 'px' | '%'
type Size = `${number}${Unit}`       // "10px" | "10%" ...
const s1: Size = '12px'              // ✅
// const s2: Size = '12'            // ❌ 缺单位
```

## 三、常见陷阱

- 数字 enum 的反向映射在仅类型使用时是多余运行时开销；字符串 enum 无反向映射、语义更安全。
- `as const + 联合` 类型更精确、能与穷尽检查配合；需要运行时枚举/反向映射才用 `enum`。

## 四、与 Electron 实例对照

本工程大量用 `as const + 联合` 描述选项集：
- 主题来源（`src/renderer/src/stores/theme.ts` 的 `ThemeSource`）；
- 权限白名单（`src/main/features/security.ts`）；
- 事件分支字段（与判别联合配合做穷尽检查，见 TS-03）。
模板字面量类型可用于 IPC 通道名、路由路径的精确类型。
