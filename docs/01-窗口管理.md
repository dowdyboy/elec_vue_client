# 01 - 窗口管理

> 对应源码：`src/main/features/windowManager.ts` | 演示页：窗口管理

## 一、原理

`BrowserWindow` 是 Electron 应用的最小单元。每个窗口都运行一个独立的渲染进程（Chromium）。

- 一个应用可创建任意多个窗口（多窗口应用：主窗口 + 设置窗口 + 弹窗…）
- 窗口是"系统原生窗口"，因此可以调用系统能力：置顶、全屏、无边框、透明

透明窗口（`transparent: true` + `frame: false`）是制作"悬浮球""桌面小组件"的基础。

## 二、关键代码

```ts
const win = new BrowserWindow({
  width: 520,
  height: 420,
  frame: false,       // 无边框
  transparent: true,  // 背景透明（需配合 frame: false）
  alwaysOnTop: true   // 置顶
})
```

窗口控制三件套：

```ts
win.minimize()                          // 最小化
win.maximize() / win.unmaximize()       // 最大化 / 还原
win.setFullScreen(!win.isFullScreen())  // 全屏切换
win.setAlwaysOnTop(!win.isAlwaysOnTop())// 置顶切换
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/windowManager.ts` + `src/main/types.ts` 到新工程
2. 在 `index.ts` 的 `whenReady` 内调用：

```ts
let mainWindow: BrowserWindow | null = null
const getMainWindow = () => mainWindow

registerWindowManager(getMainWindow)  // 窗口相关 IPC 即生效
```

3. 渲染进程（需复制 `src/preload/index.ts` 中的 `window` 分组）：

```ts
await window.api.window.create('transparent') // 创建透明窗口
window.api.window.minimize()
await window.api.window.toggleAlwaysOnTop()
```

## 四、常见问题

- **透明窗口黑色背景**：必须设置 `frame: false`，且不要在 CSS 里给 body 设置背景色
- **置顶无效**：部分 Linux 桌面环境不支持 `alwaysOnTop`
- **窗口坐标**：多显示器时使用 `screen` 模块获取坐标（见 10-屏幕信息）

## 五、扩展：任务栏进度 / 角标 / 窗口状态持久化

**任务栏进度**（`src/main/features/taskbar.ts`）——下载/导出进度提示：

```ts
win.setProgressBar(0.6)          // 0~1 进度（Windows 任务栏图标下方）
win.setProgressBar(0.6, { mode: 'error' }) // 红色状态
win.setProgressBar(-1)           // 清除进度条
app.setBadgeCount(5)             // macOS Dock 角标（未读数）
```

**窗口状态持久化**（`src/main/features/windowState.ts`）——记住用户上次的窗口位置/大小：

```ts
// 启动时恢复
const state = await loadWindowState() // 读 userData/window-state.json
if (state) win.setBounds(state)

// 变化时保存（resize/move 事件 + debounce 500ms）
win.on('resize', persist)
win.on('move', persist)
```

**无边框窗口拖动**（渲染进程 CSS，配合透明窗口）：

```css
.drag-region {
  -webkit-app-region: drag;   /* 该区域可拖动窗口 */
}
.drag-region button {
  -webkit-app-region: no-drag; /* 区域内可点击元素要声明 no-drag */
}
```

## 六、扩展：毛玻璃 / 闪屏（`src/main/features/glassEffect.ts` / `splash.ts`）

**毛玻璃效果**（平台相关）：

```ts
// macOS：窗口毛玻璃特效
win.setVibrancy('under-window')   // 'under-window' | 'titlebar' | 'fullscreen-ui'...
// Windows 11：亚克力/云母材质
win.setBackgroundMaterial('acrylic') // 'auto' | 'none' | 'mica' | 'acrylic' | 'tabbed'
```

**闪屏页**（Splash Screen）——启动时短暂显示 Logo，主窗口就绪后关闭：

```ts
// 创建主窗口前
showSplash() // 无边框、置顶、不占任务栏，加载 splash.html
// 主窗口 ready-to-show 时
closeSplash()
```

复制步骤：连同 `src/renderer/splash.html` 一起复制；electron.vite.config.ts 的 renderer 多页入口增加 splash（本工程已配置）。

**无边框窗口自定义标题栏**（演示：创建"透明无边框窗口"后可见）：

```ts
// 主进程：作用于"发起请求的窗口"（主/子窗口通用）
ipcMain.on('window:control', (event, channel) => {
  const win = BrowserWindow.fromWebContents(event.sender)
  if (channel === 'minimize') win.minimize()
  if (channel === 'maximize') win.isMaximized() ? win.unmaximize() : win.maximize()
  if (channel === 'close') win.close()
})
// 渲染进程
window.api.window.control('minimize')
```

## 七、扩展：缩放 / 尺寸限制 / 透明度 / 窗口事件（`zoom.ts` / `windowManager.ts`）

**页面缩放**（阅读类应用的字体缩放设置）：

```ts
win.webContents.setZoomFactor(1.2) // 0.5 ~ 3.0
win.webContents.getZoomFactor()
// 用户 Ctrl+滚轮缩放会触发 'zoom-changed' 事件
win.webContents.on('zoom-changed', () => { /* 同步最新倍率 */ })
```

**窗口尺寸限制与透明度**：

```ts
win.setMinimumSize(600, 400)
win.setMaximumSize(1600, 900)
win.setOpacity(0.8) // 0 ~ 1（窗口整体透明，配合透明窗口使用）
```

**窗口事件监听**（拖拽/缩放实时回调）：

```ts
win.on('will-move', () => {})    // 窗口即将移动
win.on('will-resize', () => {})  // 窗口即将调整大小
```

渲染进程：`window.api.window.setMinSize/setMaxSize/setOpacity/onEvent`、`window.api.zoom.set/reset/get/onChanged`

**内置 PDF 查看器**：`WebContentsView` 加载 `file:///path.pdf` 即用 Chromium 内置 PDF 查看器渲染（缩放/翻页/打印），无需额外配置（演示见打印页）。
