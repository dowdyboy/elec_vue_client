# 07 - 文件对话框

> 对应源码：`src/main/features/dialog.ts` | 演示页：文件对话框

## 一、原理

打开/保存文件对话框是**系统原生窗口**，**必须由主进程弹出**。渲染进程只能通过 IPC 请求主进程弹出对话框，主进程返回选中的路径。

- `showOpenDialog`：选择文件/文件夹（`properties` 控制）
- `showSaveDialog`：选择保存位置
- `showMessageBox`：消息/确认框（返回用户点击的按钮下标）

## 二、关键代码

```ts
// 打开文件：filters 控制可选类型，properties 控制单选/多选/选文件夹
const result = await dialog.showOpenDialog(win, {
  title: '选择一个文件',
  filters: [
    { name: '文本', extensions: ['txt', 'md'] },
    { name: '所有文件', extensions: ['*'] }
  ],
  properties: ['openFile'] // openDirectory / multiSelections / openFile
})
if (result.canceled) return null
return result.filePaths[0] // 多选时是数组

// 保存文件
const { canceled, filePath } = await dialog.showSaveDialog(win, {
  title: '保存文件',
  defaultPath: 'untitled.txt'
})

// 消息框：返回点击的按钮下标
const { response } = await dialog.showMessageBox(win, {
  type: 'question', // info | warning | error | question
  message: '确定要删除吗？',
  buttons: ['删除', '取消'],
  defaultId: 0,
  cancelId: 1
})
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/dialog.ts`
2. `index.ts` 中调用 `registerDialog(getMainWindow)`
3. 渲染进程：

```ts
const filePath = await window.api.dialog.openFile([
  { name: '文本', extensions: ['txt'] }
])
```

## 四、常见问题

- **parent 参数**：传入主窗口，对话框会作为子窗口居中于父窗口
- **路径校验**：对话框返回的路径可能被用户篡改，读取前仍需校验（配合 fs 封装）
- **不要用 HTML 的 `<input type="file">`**：它返回的是无系统路径的 File 对象，无法用于 Node 文件操作
