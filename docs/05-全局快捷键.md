# 05 - 全局快捷键

> 对应源码：`src/main/features/globalShortcut.ts` | 演示页：全局快捷键

## 一、原理

`globalShortcut` 注册的是**操作系统级**快捷键：应用在后台、最小化到托盘时依然生效。典型场景：截图工具（Ctrl+Shift+A 截图）、语音助手（按热键呼出）。

三点注意：

1. 必须 `app.whenReady()` 之后才能注册
2. 快捷键被其他应用占用时 `register()` 返回 `false`（要检查返回值！）
3. 应用退出前务必 `unregisterAll()`，否则快捷键残留

## 二、关键代码

```ts
// 注册：返回是否成功
const ok = globalShortcut.register('CommandOrControl+Shift+1', () => {
  win.webContents.send('shortcut:triggered', { accelerator })
})
console.log(ok ? '注册成功' : '已被其他应用占用')

// 查询是否被占用
globalShortcut.isRegistered('CommandOrControl+Shift+1')

// 注销
globalShortcut.unregisterAll()

// 退出时清理
app.on('will-quit', () => globalShortcut.unregisterAll())
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/globalShortcut.ts`
2. `index.ts` 中调用 `registerGlobalShortcut(getMainWindow)`
3. 渲染进程监听触发事件：

```ts
window.api.shortcut.onTriggered(({ accelerator }) => {
  // 收到快捷键触发，做业务处理
})
```

4. 动态开关（页面上的按钮）：

```ts
await window.api.shortcut.setEnabled(false) // 全部注销
```

## 四、快捷键语法速查

| 写法 | 含义 |
|------|------|
| `CommandOrControl+X` | Ctrl（Win/Linux）/ Cmd（macOS）|
| `Alt+X` | Alt |
| `Shift+X` | Shift |
| `F1` ~ `F24` | 功能键 |
| `MediaPlayPause` | 媒体键 |

> 跨平台建议使用 `CommandOrControl`，让应用在 Win/mac 上自动适配。
