# 06 - 剪贴板

> 对应源码：`src/main/features/clipboard.ts` | 演示页：剪贴板

## 一、原理

Electron 的 `clipboard` 模块比浏览器 `navigator.clipboard` 更强：

- 支持 **HTML 富文本**（带格式粘贴到 Word/WPS）
- 支持**图片**（nativeImage）
- 与权限系统结合（见 12-安全实践：剪贴板读取是敏感权限）

## 二、关键代码

```ts
import { clipboard, nativeImage } from 'electron'

clipboard.writeText('纯文本')
clipboard.readText()

clipboard.writeHTML('<b>加粗</b> 富文本')
clipboard.readHTML()

// 图片：渲染进程传 dataURL → 主进程转 nativeImage
const image = nativeImage.createFromDataURL('data:image/png;base64,...')
clipboard.writeImage(image)
const dataUrl = clipboard.readImage().toDataURL()
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/clipboard.ts`
2. `index.ts` 中调用 `registerClipboard()`
3. 渲染进程：

```ts
await window.api.clipboard.writeText('hello')
const text = await window.api.clipboard.readText()
await window.api.clipboard.writeImage(dataUrl)
```

## 四、最佳实践

- **权限**：`clipboard-read` 是敏感权限，配合 `session.setPermissionRequestHandler` 白名单（本工程已演示，默认拒绝非白名单权限）
- **图片格式**：Windows 上建议写入 PNG 或带格式的图片（`clipboard.write({ image, html })` 可同时写多格式）
