# 08 - 文件系统

> 对应源码：`src/main/features/fileSystem.ts` | 演示页：文件系统

## 一、原理

渲染进程默认**没有**文件系统访问能力（安全隔离）。所有文件操作必须经主进程 `fs` 执行。

本工程提供最小封装：所有 IPC 返回 `{ ok, data? | error? }`，异常不抛到渲染进程，方便页面直接展示错误。

**生产工程必做**：路径白名单校验（限制只能读写指定目录），防止渲染进程被注入恶意代码后任意读写文件。

## 二、关键代码

```ts
import { promises as fs } from 'fs'

// 统一异常包装
async function safe<T>(fn: () => Promise<T>) {
  try {
    return { ok: true, data: await fn() }
  } catch (err) {
    return { ok: false, error: err.message }
  }
}

ipcMain.handle('fs:readFile', (_e, filePath) =>
  safe(async () => (await fs.readFile(filePath, 'utf-8')).toString())
)

ipcMain.handle('fs:writeFile', (_e, filePath, content) =>
  safe(async () => {
    await fs.mkdir(dirname(filePath), { recursive: true }) // 自动建父目录
    await fs.writeFile(filePath, content, 'utf-8')
    return '写入成功'
  })
)

ipcMain.handle('fs:listDir', (_e, dirPath) =>
  safe(async () => (await fs.readdir(dirPath, { withFileTypes: true })))
)
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/fileSystem.ts`
2. `index.ts` 中调用 `registerFileSystem()`
3. 渲染进程：

```ts
const result = await window.api.fs.readFile('C:/path/file.txt')
if (result.ok) {
  console.log(result.data)
} else {
  console.error(result.error)
}
```

## 四、进阶：拖拽获取真实路径

浏览器拖拽只能拿到 `File` 对象（无系统路径）。Electron 中通过 `webUtils.getPathForFile` 获取真实路径（在 **preload** 中暴露，渲染进程即可使用）：

```ts
// preload/index.ts
import { webUtils } from 'electron'

fs: {
  // ...
  getPathForFile: (file: File) => webUtils.getPathForFile(file)
}

// 渲染进程拖拽处理
function onDrop(event: DragEvent): void {
  const files = Array.from(event.dataTransfer?.files ?? [])
  const paths = files.map((file) => window.api.fs.getPathForFile(file))
}
```

拿到真实路径后，即可继续走 `fs:readFile` 等 IPC 完成读写。

## 五、进阶：拖拽文件出窗口（webContents.startDrag）

反向操作：把应用内的文件拖到桌面/资源管理器。必须在渲染进程的拖拽事件中调用：

```ts
// 主进程（已封装在 windowManager.ts 的 drag:start 通道）
win.webContents.startDrag({
  file: filePath,
  icon: nativeImage.createFromPath('icon.png') // 拖动时显示的图标
})

// 渲染进程
function onDragStart(event: DragEvent): void {
  event.dataTransfer?.setData('text/plain', filePath) // dragstart 生效的必要条件
  window.api.drag.start(filePath) // 通知主进程开始系统拖拽
}
```

## 六、进阶：系统文件图标（app.getFileIcon）

```ts
// 主进程
const icon = await app.getFileIcon(filePath, { size: 'large' }) // 'small'|'normal'|'large'
const dataUrl = icon.toDataURL()

// 渲染进程
const res = await window.api.fileIcon.get('C:/Windows/notepad.exe')
if (res.ok) img.src = res.dataUrl
```

适合文件列表/资源管理器类应用展示文件类型图标。

## 五、安全建议

```ts
// 白名单示例：只允许读写 userData 下的 data 目录
const allowedRoot = app.getPath('userData') + '/data'
if (!filePath.startsWith(allowedRoot)) {
  return { ok: false, error: '路径不在白名单内' }
}
```
