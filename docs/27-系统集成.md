# 27 - 系统集成（权限 / 在线状态 / 缓存 / 按键 / 语言）

> 对应源码：`systemAccess.ts` / `netStatus.ts` / `sessionCleanup.ts` / `inputHook.ts` / `systemInfo.ts` / `errorHandler.ts`（扩展）

## 一、系统权限询问（systemAccess.ts，macOS）

摄像头/麦克风的授权流程——macOS 必须经主进程发起系统弹窗：

```ts
// 查询授权状态：'not-determined' | 'granted' | 'denied' | 'restricted'
systemPreferences.getMediaAccessStatus('camera')

// 发起授权弹窗（返回用户是否授予）
const granted = await systemPreferences.askForMediaAccess('camera')
```

Windows/Linux 由 Chromium 权限弹窗处理（配合 security.ts 的白名单）。

渲染进程：`window.api.system.getMediaAccessStatus()` / `askMediaAccess('camera')`

## 二、网络在线状态（netStatus.ts）

```ts
net.isOnline()                 // 当前是否联网
net.on('online', () => {})     // 恢复联网
net.on('offline', () => {})    // 断网
```

渲染进程：`window.api.net.getStatus()` + `onStatus(cb)`（拔网线实时触发）。

> 注意：`isOnline()` 只反映系统网络连通性；业务级探测（服务器是否可达）用 HTTP 请求（network.ts）。

## 三、会话缓存清理（sessionCleanup.ts）

```ts
await session.defaultSession.clearCache()      // 清 HTTP 缓存
await session.defaultSession.clearStorageData({ // 清存储（可按类型）
  storages: ['cookies', 'localstorage', 'indexdb']
})
```

场景：退出登录清 Cookie、隐私清理、排障。**注意会清掉应用自身的 localStorage**。

渲染进程：`window.api.session.clearCache() / clearStorage() / clearAll()`

## 四、按键拦截（inputHook.ts）

```ts
// 在按键到达页面之前拦截（仅窗口聚焦时生效）
contents.on('before-input-event', (event, input) => {
  if (input.key === 'F12') {
    event.preventDefault() // 吞掉按键
  }
})
```

与 globalShortcut 的区别：**应用内 vs 系统级**。场景：禁 F12 调试、禁用 Ctrl+S、自定义组合键。

渲染进程：`window.api.inputHook.setBlockF12(true)` + `onKey(cb)` 按键日志

**⚠️ 踩坑：dev 的 F12 DevTools 与吞键冲突**（本工程实测修复）：

- dev 下 F12 打开 DevTools 是 `optimizer.watchWindowShortcuts`（@electron-toolkit/utils）
  实现的，它**不检查 `event.defaultPrevented`**，无条件 `openDevTools()`；
- `before-input-event` 是 EventEmitter，**所有监听器都会执行**——即使你的吞键监听器
  先 `preventDefault()`，optimizer 照样把 DevTools 打开（监听顺序也无法解决）。
- 本工程的处理：dev 下不再对窗口调用 `watchWindowShortcuts`（仅生产启用，保留
  Ctrl+R/Ctrl+Shift+I 屏蔽），F12 的"开关 DevTools"由 inputHook.ts 统一接管，
  "吞掉 F12"开关开启后两者一并禁用。

```ts
// inputHook.ts：F12 统一处理（吞键优先，其次 dev 惯例的 DevTools 开关）
if (input.key === 'F12') {
  if (blockF12) return void event.preventDefault() // 吞键：彻底失效
  if (!app.isPackaged) { // dev：接管原 optimizer 行为
    event.preventDefault()
    contents.isDevToolsOpened()
      ? contents.closeDevTools()
      : contents.openDevTools({ mode: 'undocked' })
  }
  return
}
```

> 教训：拦截类功能要意识到"别的模块可能也在监听同一事件且不尊重 defaultPrevented"，
> 正确做法是**同一行为只保留一个实现方**。

## 五、系统语言与字体（systemInfo.ts）

```ts
app.getLocale()                       // 界面语言（zh-CN）
app.getPreferredSystemLanguages()     // 语言偏好列表
app.getFonts()                        // 系统字体（Linux 不可用）
```

场景：多语言应用初始化默认语言、字体选择器。渲染进程：`window.api.system.getInfo()`

## 六、崩溃自动恢复（errorHandler.ts 扩展）

```ts
app.on('render-process-gone', (_e, webContents, details) => {
  if (details.reason !== 'clean-exit') {
    setTimeout(() => webContents.reload(), 1000) // 1 秒后自动恢复
  }
})
```

场景：页面崩溃自动刷新（需配合"恢复前提示"避免数据丢失）。渲染进程：`window.api.error.setAutoRecovery(true)`
