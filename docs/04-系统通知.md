# 04 - 系统通知

> 对应源码：`src/main/features/notification.ts` | 演示页：系统通知

## 一、原理

系统通知（Notification）显示为操作系统原生的弹窗（Windows 右下角 / macOS 右上角），不受应用窗口影响。

**注意**：必须在**主进程**创建通知——渲染进程的 `new Notification()`（web Notification）在 Electron 中默认不可用。

## 二、关键代码

```ts
const notification = new Notification({
  title: '标题',
  body: '正文',
  icon: join(__dirname, 'icon.png')
})

// 点击通知 → 聚焦窗口（常见交互：点通知打开应用）
notification.on('click', () => {
  win.show()
  win.focus()
})

notification.show()
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/notification.ts`
2. `index.ts` 中调用 `registerNotification(getMainWindow)`
3. 渲染进程：

```ts
await window.api.notification.show({ title: '任务完成', body: '导出成功' })
// 监听点击（可选）
window.api.notification.onClicked((opts) => console.log('点击了通知', opts))
```

## 四、常见问题

- **Windows 不显示**：检查系统"通知和操作"设置中是否允许本应用通知
- **macOS 权限**：发布到 App Store 需要 `NSUserNotificationUsageDescription`（本地通知一般无需）
- **Linux 依赖**：需要桌面环境支持（GNOME 的 notification daemon）

## 五、扩展：通知动作按钮（actions）

在通知上附加操作按钮（如"立即更新 / 稍后提醒"）：

```ts
const notification = new Notification({
  title: '更新提示',
  body: '发现新版本 v2.0',
  actions: [
    { type: 'button', text: '立即更新' },
    { type: 'button', text: '稍后提醒' }
  ]
})
// 按钮点击：回传下标（0 = 第一个按钮）
notification.on('action', (_e, index) => {
  // index === 0 → 用户点了"立即更新"
})
```

注意：macOS 原生支持；Windows 需使用打包后的 toast 通知（开发模式可能不显示按钮）。

渲染进程调用：

```ts
window.api.notification.show({ title, body, actions: ['立即更新', '稍后提醒'] })
window.api.notification.onAction(({ index }) => { /* 处理按钮点击 */ })
```
