# 04 - 系统通知

> 对应源码：`src/main/features/notification.ts` | 演示页：系统通知

## 一、原理

系统通知（Notification）显示为操作系统原生的弹窗（Windows 右下角 / macOS 右上角），不受应用窗口影响。

**注意**：必须在**主进程**创建通知——渲染进程的 `new Notification()`（web Notification）在 Electron 中默认不可用。

## 二、关键代码

```ts
const notification = new Notification({
  title: '标题',
  body: '正文',
  icon: join(__dirname, 'icon.png')
})

// 点击通知 → 聚焦窗口（常见交互：点通知打开应用）
notification.on('click', () => {
  win.show()
  win.focus()
})

notification.show()
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/notification.ts`
2. `index.ts` 中调用 `registerNotification(getMainWindow)`
3. 渲染进程：

```ts
await window.api.notification.show({ title: '任务完成', body: '导出成功' })
// 监听点击（可选）
window.api.notification.onClicked((opts) => console.log('点击了通知', opts))
```

## 四、常见问题

- **Windows 不显示**：检查系统"通知和操作"设置中是否允许本应用通知
- **macOS 权限**：发布到 App Store 需要 `NSUserNotificationUsageDescription`（本地通知一般无需）
- **Linux 依赖**：需要桌面环境支持（GNOME 的 notification daemon）

## 五、扩展：通知动作按钮（actions）

在通知上附加操作按钮（如"立即更新 / 稍后提醒"）：

```ts
const notification = new Notification({
  title: '更新提示',
  body: '发现新版本 v2.0',
  actions: [
    { type: 'button', text: '立即更新' },
    { type: 'button', text: '稍后提醒' }
  ]
})
// 按钮点击：回传下标（0 = 第一个按钮）
notification.on('action', (_e, index) => {
  // index === 0 → 用户点了"立即更新"
})
```

注意：macOS 原生支持；Windows 见下方「AUMID 机制」——开发模式（未打包）下
**通知能显示但按钮会被系统剥掉**，这是 Windows 平台要求而非代码 bug。

渲染进程调用：

```ts
window.api.notification.show({ title, body, actions: ['立即更新', '稍后提醒'] })
window.api.notification.onAction(({ index }) => { /* 处理按钮点击 */ })
```

## 六、Windows 动作按钮与 AUMID 机制（踩坑必读）

Windows 10/11 的 toast 按钮要求应用的 **AppUserModelID（AUMID）已通过
"开始菜单快捷方式"注册**（ToastNotificationManager 机制）。链路：

| 环境 | 快捷方式 | 按钮 |
|------|---------|------|
| 开发模式（npm run dev） | 无 → AUMID 未注册 | ❌ 通知显示但无按钮 |
| 开发模式 + 一键创建快捷方式 | 有（带 AUMID） | ✅ 按钮正常 |
| 打包安装（build:win） | 安装程序自动创建 | ✅ 按钮正常 |

开发模式解锁方法（本工程演示页已内置按钮，源码见 notification.ts）：

```ts
// ① 应用启动时设置 AUMID（index.ts 已做）
electronApp.setAppUserModelId('com.electron')

// ② 创建带 AUMID 的开始菜单快捷方式（shell.writeShortcutLink，仅 Windows）
const shortcutPath = join(
  app.getPath('appData'),
  'Microsoft/Windows/Start Menu/Programs',
  'Electron 教学.lnk'
)
shell.writeShortcutLink(shortcutPath, 'create', {
  target: process.execPath,   // dev 指向 electron.exe；打包后即应用 exe
  args: app.getAppPath(),     // dev 时给 electron 传应用路径，否则启动裸 electron
  appUserModelId: 'com.electron' // 与 setAppUserModelId 保持一致
})
```

> 创建后需**重新发送**通知才生效。dev 下点击按钮会经快捷方式唤起新实例，
> 被单实例锁重定向到现有实例（顺带演示 second-instance 链路，见 docs/13）。
> 生产环境推荐用 `Notification.handleActivation(cb)`（Electron 39）做集中式激活处理。

macOS 补充：通知（含按钮）要求应用**代码签名**，未签名的 dev 构建通知受限；
Linux 走 libnotify，多数桌面环境支持按钮。

## 七、踩坑：快捷方式已创建，按钮还是不出来

本工程实测踩过的深层坑（现象：页面显示"AUMID 已注册"，但 toast 依然没有按钮）：

**原因**：Windows 推送通知平台（WpnUserService）自己缓存了一份"开始菜单快捷方式表"。
程序化新建的 .lnk（`shell.writeShortcutLink`）虽然文件系统与资源管理器
（`Get-StartApps` 查询）都能立刻看到，但 **WpnUserService 的缓存要等刷新
（注销/重启）才会收录**。show 时它找不到 `com.electron` 的有效注册 → 把 toast
降级为不可交互身份 → 按钮被剥掉。

排查三步（按顺序）：

1. **重启应用**重试（排除"notifier 在快捷方式创建前初始化"的时序问题）
2. 仍无效 → **注销或重启一次**（WpnUserService 缓存刷新，dev 场景最可靠的兜底）
3. 检查通知右上角是否有 **∨ 展开箭头**——Win11 会把动作按钮折叠，点击展开才可见

自查命令（PowerShell）：

```powershell
# ① 快捷方式是否被 Shell 收录（AppID 应为 com.electron）
Get-StartApps | Where-Object { $_.Name -like '*Electron*' }

# ② 通知设置里是否出现 com.electron 键（有 = 通知平台已按该身份归因）
Get-ChildItem 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Notifications\Settings' |
  Where-Object PSChildName -eq 'com.electron'

# ③ 用同一 AUMID 发送原始带按钮 toast（系统层/应用层二分定位）
[Windows.UI.Notifications.ToastNotificationManager, Windows.UI.Notifications, ContentType = WindowsRuntime] | Out-Null
$xml = [Windows.Data.Xml.Dom.XmlDocument]::new()
$xml.LoadXml('<toast><visual><binding template="ToastGeneric"><text>测试</text></binding></visual><actions><action content="按钮A" arguments="a"/></actions></toast>')
$toast = [Windows.UI.Notifications.ToastNotification]::new($xml)
[Windows.UI.Notifications.ToastNotificationManager]::CreateToastNotifier('com.electron').Show($toast)
```

> ③ 的 toast 若也无按钮 → 系统层缓存问题（执行步骤 2）；若有按钮 → 应用层时序问题
> （执行步骤 1）。**打包安装（build:win）后无此问题**：Squirrel 在安装期创建快捷方式，
> 距首次通知早已过了缓存刷新窗口。
