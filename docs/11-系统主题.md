# 11 - 系统主题

> 对应源码：`src/main/features/theme.ts` | 演示页：系统主题

## 一、原理

`nativeTheme` 是主进程判断"系统当前明暗主题"的权威来源：

- `themeSource`：应用的主题偏好 —— `'system'`（默认）/ `'light'` / `'dark'`
- `shouldUseDarkColors`：**实际生效**是否为暗色（由 source + 系统设置共同决定）
- `updated` 事件：系统主题变化 / source 变化时触发

**联动机制**：`themeSource: 'system'` 时，用户切换 Windows/macOS 系统主题 → `updated` 事件 → 主进程推送渲染进程 → UI 主题实时跟随。这是桌面应用"跟随系统外观"的标准实现。

## 二、关键代码

```ts
import { nativeTheme } from 'electron'

// 设置偏好
nativeTheme.themeSource = 'dark' // 'system' | 'light' | 'dark'
nativeTheme.themeSource = 'system' // 恢复跟随系统

// 查询
const isDark = nativeTheme.shouldUseDarkColors

// 监听系统主题变化
nativeTheme.on('updated', () => {
  win.webContents.send('theme:updated', {
    shouldUseDarkColors: nativeTheme.shouldUseDarkColors
  })
})
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/theme.ts`
2. `index.ts` 中调用 `registerTheme(getMainWindow)`
3. 渲染进程（以 Naive UI 为例，其他组件库同理）：

```ts
// 初始化
const state = await window.api.theme.getState()
isDark.value = state.shouldUseDarkColors

// 切换主题源
await window.api.theme.setSource('dark')

// 跟随系统
window.api.theme.onUpdated(({ shouldUseDarkColors }) => {
  isDark.value = shouldUseDarkColors
})
```

```vue
<n-config-provider :theme="isDark ? darkTheme : null">
```

## 四、最佳实践

- 主题状态放在**全局 store**（本工程 `stores/theme.ts`），供所有页面共享
- 不要用浏览器 `prefers-color-scheme` 判断——以主进程 `shouldUseDarkColors` 为准（它兼顾了 `themeSource` 覆盖）
- 自定义 CSS 变量也要跟随主题（本工程 `main.css` 中定义了 `--border-color` 等变量）
