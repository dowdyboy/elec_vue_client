# 17 - 桌面捕获

> 对应源码：`src/main/features/desktopCapture.ts` | 演示页：桌面捕获

## 一、原理

**desktopCapturer**：枚举系统所有屏幕与窗口源（可带缩略图），是录屏、屏幕共享（OBS、视频会议）的基础。

**capturePage**：截取指定 webContents 的当前画面。

本页演示静态链路：枚举源 → 截取 → 保存 PNG。持续录屏需再叠加 `getDisplayMedia`/定时截图方案。

## 二、关键代码

```ts
import { desktopCapturer } from 'electron'

// 枚举屏幕/窗口源（含缩略图）
const sources = await desktopCapturer.getSources({
  types: ['screen', 'window'],
  thumbnailSize: { width: 320, height: 180 }
})
// sources[i].name / sources[i].thumbnail.toDataURL()

// 截取当前窗口
const image = await win.webContents.capturePage()
const dataUrl = image.toDataURL()

// dataURL → PNG 文件
const base64 = dataUrl.split(',')[1]
await fs.writeFile(filePath, Buffer.from(base64, 'base64'))
```

## 三、复制到新工程的步骤

1. 复制 `src/main/features/desktopCapture.ts`
2. `index.ts` 中调用 `registerDesktopCapture(getMainWindow)`
3. 渲染进程：

```ts
const sources = await window.api.capture.getSources() // 枚举屏幕/窗口
const res = await window.api.capture.capturePage()    // 截当前窗口
await window.api.capture.savePng(res.dataUrl)         // 保存 PNG
```

## 四、进阶说明

- **持续录屏**：定期 capturePage 合成视频流，或用 `getDisplayMedia` + MediaRecorder
- **Windows 注意**：部分系统环境对窗口捕获有权限/兼容限制（Win7 不支持某些源）
- **性能**：缩略图尺寸不要过大（本工程 320×180 足够预览）
