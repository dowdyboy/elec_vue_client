# 26 - 平台特性（Windows 任务栏 / macOS Dock / kiosk / 媒体控制 / Thumbar / 闪烁）

> 对应源码：`src/main/features/taskbar.ts`（扩展）+ `windowManager.ts`（kiosk）| 演示页：平台特性

## 一、Windows 任务栏高级

```ts
// 跳转列表（JumpList）：右键任务栏图标的最近文件/任务
app.setJumpList([
  { type: 'recent', items: [{ type: 'file', path: 'C:/file.txt' }] }
])

// 图标叠加角标（OverlayIcon）：图标右下角的小图标（"新消息"红点等）
win.setOverlayIcon(nativeImage.createFromPath('icon.png'), '提示文字')
win.setOverlayIcon(null, '') // 移除
```

## 二、macOS Dock 能力

```ts
// Dock 右键菜单
app.dock.setMenu(Menu.buildFromTemplate([
  { label: '显示主窗口', click: () => win.show() }
]))

// 最近文档（出现在 Dock 右键"最近使用"）
app.addRecentDocument(join(app.getPath('documents'), '示例.txt'))

// Dock 图标弹跳动画（下载完成提示等）
app.dock.bounce('informational') // 'informational' 轻提示 / 'critical' 持续
```

## 三、kiosk 锁定全屏（`windowManager.ts`）

```ts
win.setKiosk(true)  // 进入：锁定全屏，Esc/系统快捷键无法退出
win.setKiosk(false) // 退出（应用内按钮触发）
```

适合：自助终端、大屏展示、电子广告屏。注意**退出方式需应用内预留**（教学演示用开关，生产用密码/手势）。

## 四、系统媒体控制（MediaSession，纯渲染进程）

播放器类应用接入系统媒体面板（Windows 媒体浮出控件 / macOS 控制中心）：

```ts
navigator.mediaSession.metadata = new MediaMetadata({
  title: '曲目名', artist: '歌手', album: '专辑'
})
navigator.mediaSession.playbackState = 'playing' // 'paused' | 'none'
// 处理系统面板的播放/暂停/下一曲按钮
navigator.mediaSession.setActionHandler('play', () => { /* ... */ })
navigator.mediaSession.setActionHandler('pause', () => { /* ... */ })
```

## 五、复制到新工程的步骤

1. 复制 `src/main/features/taskbar.ts`（含 JumpList/Overlay/Dock 扩展）
2. 复制 `src/main/features/windowManager.ts`（kiosk 部分在 window:setKiosk 通道）
3. `index.ts` 调用 `registerTaskbar(getMainWindow)` + `registerWindowManager(getMainWindow)`
4. 渲染进程：`window.api.taskbar.setJumpList(files)` / `setOverlay(true)` / `setDockMenu()` / `addRecentDocument()`；`window.api.window.setKiosk(true)`

> 各能力均有平台限制（代码已检测并提示），跨平台应用需判断 `process.platform`。

## 六、Windows 缩略图按钮（Thumbar）

鼠标悬停任务栏图标时，缩略图下方出现的按钮组（媒体播放器式控制）：

```ts
const icon = nativeImage.createFromPath('icon.png')
win.setThumbarButtons([
  {
    tooltip: '播放 / 暂停',
    icon,
    click: () => win.webContents.send('taskbar:thumbar-clicked', 'playpause')
  },
  {
    tooltip: '下一首',
    icon,
    click: () => win.webContents.send('taskbar:thumbar-clicked', 'next')
  }
])
win.setThumbarButtons([]) // 传空数组移除
```

渲染进程：`window.api.taskbar.setThumbar(true)` + `window.api.taskbar.onThumbarClicked((action) => ...)`

- **仅 Windows**（Windows 7+）；macOS 等价物是 Touch Bar（已废弃）与媒体控制（MediaSession）
- 按钮图标建议 16x16/20x20/24x24 多尺寸 nativeImage，或使用系统图标
- 典型场景：播放器（播放/暂停/下一首）、下载器（暂停/继续/取消）

## 七、任务栏图标闪烁（flashFrame）

应用在后台时引起用户注意的经典方式（新消息提醒）：

```ts
win.flashFrame(true)                       // 开始闪烁（Windows 任务栏 / Linux 桌面）
win.flashFrame(false)                      // 熄灭
// 用户点击窗口时：win.once('focus', () => win.flashFrame(false))
```

- **仅 Windows / Linux**；macOS 等价物是 `app.dock.bounce('informational')`（见上文）
- 演示用 3 秒定时熄灭；生产应在 `focus` 事件时熄灭（用户已注意到）
- 进阶：Windows 可用 `win.setOverlayIcon`（红点角标）替代闪烁，干扰更小

渲染进程：`window.api.taskbar.flashFrame()`
