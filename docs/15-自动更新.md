# 15 - 自动更新

> 对应源码：`src/main/features/autoUpdater.ts` | 演示页：自动更新

## 一、原理

`electron-updater` 是生产应用标配：启动后向更新服务器查询版本 → 发现新版本 → 下载安装包 → 重启完成更新。

配置链路：
- 开发模式读取 **dev-app-update.yml**（本工程已存在）
- 生产模式读取打包时生成的 **app-update.yml**（由 electron-builder.yml 的 `publish` 生成）

⚠️ **dev 模式检查的前提**：electron-updater 在**未打包环境默认直接跳过检查**
（日志打印 `Skip checkForUpdates because application is not packed and dev update config
is not forced`，且不触发任何事件——表现为页面"检查更新"点了没反应）。必须在
`registerAutoUpdater` 里设置 `autoUpdater.forceDevUpdateConfig = true` 才会读取
dev-app-update.yml 真实执行检查（本工程已设置）。打包后不受影响。

## 二、关键代码

```ts
import { autoUpdater } from 'electron-updater'

autoUpdater.autoDownload = false // 由用户确认后再下载

// 状态事件（推送到渲染进程展示）
autoUpdater.on('update-available', (info) => { /* 有新版 */ })
autoUpdater.on('download-progress', (p) => { /* p.percent */ })
autoUpdater.on('update-downloaded', () => { /* 下载完成 */ })
autoUpdater.on('error', (err) => { /* 错误处理 */ })

// 控制
autoUpdater.checkForUpdates()      // 检查
autoUpdater.downloadUpdate()       // 下载
autoUpdater.quitAndInstall()       // 退出并安装
```

## 三、接入真实更新服务器

1. 把构建产物（安装包 + `latest.yml`）放到服务器目录
2. 修改配置：

```yaml
# electron-builder.yml（生产）
publish:
  provider: generic
  url: https://your-server.com/updates

# dev-app-update.yml（开发）
url: http://localhost:8080/updates
```

3. `npm run build:win` 打包并上传 → 用户启动即自动检查

## 四、复制到新工程的步骤

1. 复制 `src/main/features/autoUpdater.ts`
2. `index.ts` 中调用 `registerAutoUpdater(getMainWindow)`
3. 渲染进程：

```ts
await window.api.update.check() // 触发检查
window.api.update.onStatus((status) => { /* 展示状态 */ })
```

> 注意：electron-updater 需配合 electron-builder 的 `publish` 配置与打包产物命名规范（`latest.yml` 自动生成）。
